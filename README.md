One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

`main.py` (Python 3.13, stdlib only) writes the excuse to `/output/entry.txt`:

> A security check flagged my own to-do list, so I missed the deadline asking for permission to read it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
